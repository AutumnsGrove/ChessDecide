# ChessDecide

A benchmark that **rates decision models at chess**. Each model (Jev, D1 Ultra, …) plays a
**series of games against Stockfish** on an adaptive ladder, and we estimate its **Elo with a
confidence interval**. A lichess-style dark web UI lets you watch any game live or play it back
move by move. Costs are tiny and capped (a game ≈ half a cent, a 25-game series ≈ $0.10).

## The idea

Decision models take a `state` plus typed questions (`choice`, `noul`, `score`) and return
calibrated answers: no prose, free output tokens, very cheap. Chess gives a closed set of legal
moves, so "which move is best?" is a `choice` question and illegal moves are impossible (the
options are generated by a rules library, never by the model). The question is how a model built
for quick general decisions copes in an environment it was never trained for.

- **Headline:** Elo on the ChessDecide Stockfish ladder (adaptive blocks of 5 games; weak levels
  below Stockfish's 1320 floor built from random-move mixes, calibrated with free CPU games).
- **Explanation:** every ply is judged by Stockfish (eval bar, blunder flags, ACPL).
- **Arms, reported separately:** `clean` (bare options, default), `hinted` (adds capture/check/mate
  text), `image` (board picture instead of FEN; optional).

## Scope (locked)

- **Stack:** TypeScript, SvelteKit (raw CSS, no Tailwind), Drizzle over SQLite/D1, `chess.js`,
  `chessground`, Stockfish behind an `Engine` adapter (other UCI engines pluggable).
- **Phases:** (1) run locally, publish results to a read-only Cloudflare site; (2) run live on
  Cloudflare (Durable Objects + Stockfish container/server); (3) scale to many models and hundreds
  of games. Same core, swapped adapters.
- **v1 order:** Viewer with a mock player → one real Jev game (go/no-go) → ladder, Series, Elo → publish.
- **Roster:** `typesafe/jev-1.14`, `liquid/d1-ultra` first.
- **Budget:** hard cap per run, default $1.00, estimate-first. No generated commentary (costs money).
- **Later:** model vs model, other engines, position suite, text-model arm.

## Before building

1. `OPENROUTER_API_KEY` in the environment (never committed).
2. Stockfish installed (`brew install stockfish`, or the binary on `PATH`).
3. Read `docs/IMPLEMENTATION.md` and follow its task order.

## Non-goals (v1)

No hosted live runs yet, no auth, not a chess engine, no human-vs-model play, no per-model prompt
tuning, no text-model spend, no generated commentary.
